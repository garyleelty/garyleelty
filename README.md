#### 🛠 What I'm building

**[agentledger](https://github.com/garyleelty/agentledger)** — what did that
coding agent actually cost you?

Reads the session logs thirteen coding agents — Claude Code, Codex, OpenCode,
Gemini CLI, Qwen Code and more — already leave on disk, and turns them into
tokens and dollars. Zero dependencies, no network calls, MIT. Five of the
thirteen adapters exist in no other tool. The part most tools get wrong:
cache reads and cache writes bill at different rates from fresh input, and
they are the overwhelming majority of real traffic.

```bash
brew install garyleelty/agentledger/agentledger   # or: curl -fsSL .../install.sh | sh
```

**[guandan](https://github.com/garyleelty/guandan)** — 掼蛋 in the browser.

Full official rules (级牌升级、逢人配、进贡还贡、同花顺、天炸), single-player
vs AI and P2P multiplayer. Pure frontend, no account, no install — open a

**[mouse-journey](https://github.com/garyleelty/mouse-journey)** — your daily
mouse mileage, as a road trip across China.

Offline Electron app: real routes and landmarks, milestones, mounts, health
reminders, and a ghost racer running against yesterday's you.

**[ai-native-markdown](https://github.com/garyleelty/ai-native-markdown)** —

Local-first writing with AI assist — continue, polish, summarize, reformat.
Works offline, dark/light themes, no data leaves the machine.
