#### 🛠 What I'm building

**[agentledger](https://github.com/garyleelty/agentledger)** — what did that
coding agent actually cost you?

Reads the session logs Claude Code, Codex and OpenCode already leave on disk and
turns them into tokens and dollars. Zero dependencies, no network calls, MIT.
The part most tools get wrong: cache reads and cache writes bill at different
rates from fresh input, and they are the overwhelming majority of real traffic.

```bash
npx agentledger-cli        # or: curl -fsSL .../install.sh | sh
```

**[ai-native-markdown](https://github.com/garyleelty/ai-native-markdown)** —

Local-first writing with AI assist — continue, polish, summarize, reformat.

**[opencode-plugin-goal](https://github.com/garyleelty/opencode-plugin-goal)** —
